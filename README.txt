ASBER ALI — SINGLE-PAGE PORTFOLIO

FILES
- index.html  Main one-page portfolio structure
- style.css   Glassmorphism styling, responsive layout and animations
- script.js   Theme studio, saved color choices, scroll reveals and navigation effects

HOW TO RUN
1. Keep all three files in the same folder.
2. Open index.html in a modern browser.
3. For local development, you can use the VS Code Live Server extension, but a local server is not required for the basic page.

CUSTOMIZE
- Open the Theme button in the top navigation to change accent colour, page background, glass tint and blur.
- Your selected theme is saved in localStorage in the browser.
- Edit the project descriptions, education details and links in index.html.
- Edit the default theme and quick palettes in script.js.

TECHNOLOGY
HTML5, CSS3, vanilla JavaScript, Bootstrap 5.3.8 (CDN).
No React, build step, backend, or additional JavaScript framework is used.

NOTES
- Bootstrap and Google Fonts are loaded from CDNs, so an internet connection is needed for those external assets.
- The email and GitHub links are editable in index.html.
- There is no backend contact form; the email buttons use mailto links.
